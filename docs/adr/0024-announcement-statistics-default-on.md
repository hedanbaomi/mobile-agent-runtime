# ADR-0024：公告统计默认开启

日期：2026-10-06。状态：采纳；由所有者在本轮明确要求，替代 R15/D07 和公告专题的默认关闭初值。

## 决定

没有 `stats_enabled` 设置的安装在公告仓储初始化时，事务写入开启状态并生成独立随机统计 ID；新安装无需先进入设置即可记录安装与活动。已有开启/关闭选择保持，特别是保存的关闭状态不因升级或重新创建仓储而开启。非法已有值继续按关闭处理，不回退默认。

设置明确说明默认开启、可随时关闭及上传范围。关闭仍取消上传、清队列、删除统计身份与去重标记；公告缓存及灰度身份保留。重新开启使用新统计 ID。事件白名单、数据保留、应用域隔离、与 Provider 的认证分域均不变；默认开启不代表增加聊天、文件或其他遥测字段。

## 取舍与验证

保持默认关闭不符合本轮产品要求；强制改写所有旧安装会覆盖用户选择，故不采用。仅改 UI 开关或读取默认值无法创建统计身份，也不能产生真实活动事件，故初始化必须持久化状态与身份。

测试覆盖无设置时直接产生 install_seen/app_active、同一数据库重建仓储保持身份与去重、保存关闭后重建仍无身份和事件、关闭清队列以及重新开启生成新身份。客户端默认值调整不要求服务端 schema、统计 API 或生产数据库迁移。
