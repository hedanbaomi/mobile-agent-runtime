Icon · Selected Concept

沙箱火花 Sandbox Spark

隔离框包裹执行火花 —— skill 只在受控边界内运行,正是本产品的核心承诺。底色 #66CCFF 呼应彩蛋主题;单色轮廓版保证 Android themed icon 成立。S1 框线火花已定稿为正式设计稿,母版见 docs/design/source/ic-launcher-*.svg。

Construction · 108 画布与安全区

  • 画布 108×108;前景约束在中央 Ø72(66%) 安全区内,四角遮罩裁切不碰形
  • 框线 stroke 4.6、内框 54×54 r15;星芒 30×30 居中,与框留 ≈9 呼吸缝
  • 双色即可:底色 #66CCFF,线稿 #003B52;不依赖渐变与阴影
  • 28px 缩略下星形仍可辨(右侧尺寸验证)

Refinements · 三个精修方向(S1 已定稿)

S1 · 框线火花定稿

最干净的读法:框 = 沙箱,星 = 执行。28px 仍清晰,单色 themed 完全一致。

S2 · 轨道卫星未采用

右上角卫星点带出「agent 循环调度」隐喻;代价是小尺寸下卫星点接近噪点。

S3 · 负形舱体未采用

实心深色舱体、星形透出底色,体量最重;深色壁纸上对比强,但「框」的语义弱于 S1。
