# 软件页面矢量设计稿清单

本目录包含 Android 客户端软件七类核心页面的高保真矢量设计稿（全量禁用 Emoji，采用纯文本、状态色阶与矢量图标）。

## 1. 矢量稿文件列表

- [scr-chat-01-light.svg](scr-chat-01-light.svg): Chat 主对话流、气泡布局、引用卡片与工具确认卡片（浅色主题）

- [scr-agent-01-light.svg](scr-agent-01-light.svg): Agent Profile 编辑、Prompt 版本对比与模型角色分配（浅色主题）
- [scr-prov-01-dark.svg](scr-prov-01-dark.svg): BYOK 服务商配置、Keystore 密钥掩码与连通性探针（深色主题）
- [scr-know-01-light.svg](scr-know-01-light.svg): 知识库总览、文档明细与视觉等待横幅（浅色主题）
- [scr-skill-01-dark.svg](scr-skill-01-dark.svg): Skill 沙箱管理、安全清单与调用审计日志（深色主题）
- [scr-ann-01-light.svg](scr-ann-01-light.svg): 公告中心、置顶横幅与强制确认模态弹窗（浅色主题）
- [scr-sett-01-dark.svg](scr-sett-01-dark.svg): 设置主页、隐私开关、数据备份与 AGPL 许可证（深色主题）
- [scr-chat-03-66ccff.svg](scr-chat-03-66ccff.svg): Chat 主对话流、气泡布局、引用与工具确认卡片（66ccff 主题）
