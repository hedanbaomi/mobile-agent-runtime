# ADR 0012：Skill 卸载与历史数据边界

日期：2026-09-26（Asia/Taipei）。状态：本地实施。

## 背景

停用 Skill 只阻止当前调用，安装记录仍在列表中。用户需要卸载入口，同时历史对话可能引用原安装、审计记录必须可追溯，重新导入不得继承旧授权。

## 决定

卸载以安装 ID 为单位，在一个数据库事务中解除当前 Agent 绑定、撤销该安装的旧式与类型化授权、使未消费的批准过期，并删除活跃安装记录。旧会话快照、调用审计和持久 Skill 记忆保留，但不会自动绑定到新安装。相同包重新导入生成新安装 ID，须重新确认权限。

保留包元数据供历史识别。只有其他安装或不可变会话快照仍需要原包时才保留包字节；否则清除包字节。历史导出通过已撤销授权中的原安装 ID 找回对应包，不把旧授权恢复为可执行状态。

## 替代方案及代价

仅增加“停用”别名无法让用户从安装列表中移除 Skill。级联删除快照、审计或记忆会破坏历史与用户资料；保留全部包字节则造成不必要的存储占用。按会话历史保留包字节需要卸载时扫描历史快照，代价是卸载事务时间随历史量增长；后续如需优化，必须保持相同保留语义。

## 验证

`SkillRepositoryTest` 覆盖解绑、撤销、历史导出、重装新身份、其他 Skill 与记忆不受影响，以及不再需要时清理包字节。独立只读审查未发现卸载路径的确定问题。真机卸载与重装验收仍未执行；本轮验证记录见 [HANDOFF](../../HANDOFF.md)。
